# pen.devの運用

## 運用方針

- UIはpen.devの方をデザインのSSoT寄りで運用する
- 選択状態ごとに「画面」を複製して並べる
- pen.devで表現できない内容もあるため、Angular UIとの厳密な一致は求めない。

## 編集について

エージェントからの編集時、以下のルールに従う

- pen.devアプリが起動している場合
  - .penファイルを**直接編集しない**
  - MCPツールを経由してアプリ上で編集する
  - 現在のセッションでMCPが利用できない場合、先に復旧を依頼する
- pen.devアプリが起動していない場合
  - ファイルを直接編集する
